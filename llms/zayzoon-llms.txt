# ZayZoon

> ZayZoon is an Earned Wage Access (EWA) and financial-wellness provider, founded in 2014,
> with offices in Calgary, Alberta and Scottsdale, Arizona. Employees of participating
> businesses can draw a portion of already-earned wages before payday. ZayZoon is sold
> through payroll, PEO and HCM platforms — it advertises 300+ payroll and HCM integrations —
> and is free for employers. NMLS ID 2635812.

## Status of the API surface

ZayZoon operates a partner API that payroll and HCM platforms use to exchange employee,
hours-worked and payroll-deduction data, and it markets that integration on its own
partner pages. It publishes **no public developer portal, no API reference, and no
machine-readable contract** — no OpenAPI, Swagger, AsyncAPI, GraphQL SDL, Protobuf, WSDL
or Postman collection was found on any ZayZoon host. Integration access is arranged
through the partner program rather than self-service signup. This file is generated by
API Evangelist from ZayZoon's public surface; it is not published by ZayZoon.

## Fees

ZayZoon publishes no API pricing. The consumer fee schedule is in the USA Terms of Service:
Near Instant Transfer (including Venmo and Zelle) carries a flat Processing Fee that "will
not exceed $5 per transfer" and is shown in the app before authorization; Boost gift cards
and the ZayZoon Visa Card are $0. Connecticut consumers pay $4 for expedited transfers and
may receive one such payout per pay period. There is no subscription or cancellation fee,
and there is no cost for employers.

## Security and compliance

- [Security program](https://www.zayzoon.com/security): SOC 2 Type II (available on request),
  TLS 1.2+, third-party penetration testing several times a year, recurring vulnerability
  scanning, WAF and DDoS protection. Security contact: security@zayzoon.com.
- [Trust Center](https://app.vanta.com/zayzoon/trust/3q6v6nbz0d1g20l1brgbhs): Vanta-hosted,
  renders client-side.
- ISO 27001 is held by ZayZoon's cloud infrastructure providers (AWS, GCP), not by ZayZoon.
- No RFC 9116 security.txt and no published bug bounty.
